# Svelte capabilities walkthrough

## Source

<https://svelte.dev/tutorial/svelte>

## set up

```bash
nvm use 25.2.1
npx sv@0.15.3 create --template minimal --types ts --add prettier eslint --install npm svelte-tutorial
cd svelte-tutorial
```

## run

```bash
npm run dev
```
